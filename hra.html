✅ LEGITIMNÍ PROVOZ (NESESTŘELOVAT — NECHAT PROJÍT!) ODMĚNA: +50 SKÓRE, +5 ◈

Bezpečná, šifrovaná nebo autentizovaná síťová komunikace: HTTPS / TLS 1.3, SSH-2.0 KEY AUTH, GET /api/health 200 nebo DNSSEC VERIFIED. Musí bezpečně dorazit do Server Core!

[1] TLS Šifrování — Nešifrovaný přenos

Indikátory: HTTP / PLAINTEXT LOGIN, FTP ANONYMOUS PASS, TELNET ROOT SESSION, ARP SPOOF SNIFFER.

Riziko a obrana: Přenos hesel v otevřeném textu lze snadno odposlechnout (Man-in-the-Middle). Nasazení TLS 1.3 spojení zašifruje.

[2] Phish Scanner — Podvody a Malware

Indikátory: podpora@mirosoft-security.com, FAKTURA_2026.pdf.exe, banka-overeni-uctu.xyz, FAKE OAUTH CONSENT.

Riziko a obrana: Typosquatting domén a spustitelné přílohy .pdf.exe kradou přihlašovací údaje. Phish Scanner je okamžitě izoluje.

[3] WAF / SQL Štít — Webové injekce

Indikátory: ' OR 1=1 --, UNION SELECT * FROM users, <img src=x onerror=alert(1)>, ../../etc/passwd.

Riziko a obrana: SQL Injection, XSS a Path Traversal útočí na databázi a prohlížeč uživatelů. Web Application Firewall (WAF) je odfiltruje.

[4] DDoS Rate-Limiter — Zahlcení sítě

Indikátory: UDP BOTNET FLOOD, TCP SYN FLOOD 45 Gbps, HTTP GET SPAM x9999, ICMP AMPLIFICATION.

Riziko a obrana: Masivní záplava požadavků z botnetu vyčerpá kapacitu serveru. Rate-Limiter omezí tok z útočných IP adres.
